# HTTPS のしくみ（教育用）

HTTP と HTTPS の違いと、HTTPS で使われている **TLS（ハイブリッド暗号方式）** のしくみを、自分で操作しながら学ぶ教育用の Web アプリです。

## 学べること

教科書（情報 I「安全な通信」）の TLS の範囲を、全3章・12枚のスライドで、自分で操作しながら学びます。ほとんどのスライドに「🎯 やってみよう」（操作の課題）があり、クリアすると次のスライドへ進めます。

1. **HTTP と HTTPS**：盗聴者になって HTTP と HTTPS の通信をのぞき比べる、HTTPS は TLS（はじめは SSL と呼ばれていた）で暗号化していること、アドレスバーの https:// と鍵マーク
2. **ハイブリッド暗号方式**：共通鍵暗号方式と公開鍵暗号方式のふり返り、データのやりとりには処理が速い共通鍵暗号方式・共通鍵を送るときは公開鍵暗号方式を使うこと、共通鍵を共有するまでの①〜⑥の手順、共通鍵は通信している間だけの使い捨てであること
3. **まとめ**：HTTP と HTTPS の特徴の仕分け、8問のまとめテスト（採点・見直し付き）

### さわって確かめる（いろいろな操作）

| 操作 | スライド |
| --- | --- |
| **カーソル移動** | 盗聴者になって、虫めがねで HTTP と HTTPS の通信をのぞき比べる |
| **クリック** | ブラウザのタブを切りかえて鍵マークをクリックし、保護の状態を確かめる／暗号方式のカードを裏返す／ページを開き直して、共通鍵が新しくなることを確かめる |
| **ドラッグ** | 通信要求・公開鍵・暗号化した共通鍵・データの札を Web ブラウザと Web サーバの間で送る（公開鍵はサーバ → ブラウザ、途中で盗聴者がコピーする）／共通鍵を暗号化する鍵を選ぶ／場面や特徴のカードを仕分ける |
| **タップ** | 手順を並べる／問題に答える |

ドラッグの操作は、タップで選んでからタップで置く方法でもできます（スマホ・タブレット向け）。

### 問題の種類

- **予想問題**：操作の前に「どうなると思う？」と考える問題。答えるまで次のスライドへ進めません。正解の位置は問題ごとにばらばらです
- **体験問題**：場面を仕分ける、共通鍵を暗号化する鍵を選ぶ、手順を並べる、特徴を仕分けるなど、自分で操作する問題
- **確認問題**：最後のまとめテスト。まとめテストの結果画面はスクリーンショットで提出する想定です（結果はサーバに保存されません）

パワーポイントのスライドのように、画面下の「前へ」「次へ」ボタンやスライドのクリック・タップで1枚ずつ進めます（← → ・スペースキーでも操作できます。問題や「やってみよう」のあるスライドではクリックで進みません）。

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-https-simulator/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-https-simulator/ （`.github/workflows/deploy-ftp.yml`）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります。
